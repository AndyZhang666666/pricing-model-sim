# 模型假设 · conserved-cohort-v2

## 参数来源

默认价格、获客成本、转化、留存、平台抽成和切换摩擦全部为作者构造的演示输入，未从真实业务数据校准。不把它们描述为应用商店统一费率、行业标准或经过验证的经验范围。具体数值以 lib/model.js 与 data/presets.json 为准。

## 留存与时间

- 第 k 月用 r(30×(k−1)) 代表整月，首月为注册时点的 100%。不是按月内积分，可能显著高估首月，不承诺对 LTV 的误差上限。
- 正值锚点间保持既有的 log-day / log-retention 插值；涉及零值的区间对比例作线性插值，零尾部保持为零。
- 全局幂律或指数形态用于尾部外推。输入需有限、不重复、0–100% 且单调不增；不模拟流失后的回流。
- 订阅生存率按 S^α 假设，α 不证明真实订阅者更粘，也不代表完整选择效应。

## 人群与切换

每名新增用户为共同分母。初始潜在解锁人群乘以留存、付费意愿衰减和“尚未分流的条件份额”得到本月解锁池。达到阈值后，切换比例只作用于本月剩余池；分流者分别进入订阅或切换流失，不在以后重复分流。

月末发生切换，次月起按订阅曲线计费；没有第二次试用。这是模型规则，不是已验证的用户行为。逐月状态表与导出暴露这一规则。

## 价格与财务口径

价格不反馈影响转化、留存、使用量或选择效应。平台抽成仅按一个固定比例处理。收入未扣履约、研发、税费、退款与坏账，不等于利润。回本只比较累计折现渠道收入与 CAC，CAC=0 时不适用。

次数与计费月数直接累计，零价格下仍可记录数量；数量不是已发生的真实付费。并列与零值保持原意，不为展示效果强行排名。

## 敏感性

一次覆盖一个字段，其他输入保留当前值。连续参数的边界只在当前模型内细化；免费集数等离散档位报告相邻档位，不伪装成实际可选的精确小数。未观察到首项变化不等于参数无业务影响，也不排除并列或扫描范围外的变化。
