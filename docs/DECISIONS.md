# 关键产品与工程决策

## 用同一分母讲清楚钱从哪里来

每名最初新增用户是三机制比较的共同分母，未付费者计零；月度存量变现效率另列。图中累计折现贡献与回本月份使用同一序列。未折现收入与 LTV 分开，不把渠道收入覆盖 CAC 说成净利润转正。

## 状态转移先守恒，再谈哪个机制好

本轮复现了旧模型的比例混用：初始可付费群体耗尽后，后续仍可从原池重复分流。修正为条件剩余份额，并公开逐月解锁池、转订阅、流失与计费人群。月末切换、次月计费，避免同月重复全额计费。旧版产物按新版本重算，不把数值变化包装成实际收益提升。

## 保留比较，不制造唯一答案

并列时明确并列；次位 LTV 为零时不计算无意义的相对优势；零 CAC 不伪造回本月。结论读取本轮数据，不凭低留存、产品类别或默认参数编出因果解释。案例点评改为下一步需要的用户与业务证据。

## 扫描必须真的只改变一个字段

使用深层字段覆盖，保留所有其他当前假设。旧版按顶层对象替换会把同组其他参数退回默认值，已新增回归防止再次出现。图表使用数值横轴，线段不平滑伪造采样；不以“斜率最大”为调价指令。

## 输入有确认、取消与恢复

曲线拖动锁定最初锚点日期，并维持后续不增；数字输入暂存，回车 / 失焦确认，Esc 取消，清空输入不立即把全曲线改为零。本机草稿校验后重算，不保存旧结论；损坏或禁用存储仍能比较和导出。

## 视觉服务核算

保留四工作区和原技术栈，桌面分列、窄屏单列，页签两列；表格在自己的容器横向滚动。用蓝 / 墨 / 灰与线型表示数据，不新增装饰图或营销式首屏。逐月状态按需展开，默认比较保持清晰。

## 不声称完成的事

没有校准真实价格弹性、留存选择效应或收益分布；没有真实业务实验、完整利润核算、真人研究或全量无障碍认证。数学回归和浏览器验收不能替代这些证据。
